# 项目目录说明

本说明用于替代可能出现乱码或版本不一致的旧目录说明。

## 根目录

- `README.md`：统一项目说明入口。
- `run.ps1` / `run.bat`：免安装运行脚本。
- `api.ps1`：API 辅助脚本。
- `runtime`：随项目携带的 JDK/运行依赖。
- `lib`：Java 依赖包。
- `build-classes`：Java 编译输出目录。

## 后端目录

- `source/server/FrontendApiServer.java`：HTTP API 入口，注册所有 `/api/*` 接口。
- `source/agent/PlatformOrchestrator.java`：完整任务编排入口。
- `source/agent/MissionDslModel.java`：统一任务模型与结构化 DSL Schema。
- `source/agent/DeviceRegistry.java`：内存级设备注册、心跳、故障和恢复。
- `source/agent/DdsCommunicationService.java`：DDS 通信统一抽象与模拟 fallback。
- `source/agent/MissionExecutionService.java`：可回放任务执行时间线。
- `source/agent/AdaptiveRoutePlanner.java`：A*/Dijkstra 动态路径规划算法。
- `source/agent/DynamicTaskScheduler.java`：基于动态权重评分的贪心任务调度算法。
- `source/nlu`：自然语言到 DSL/Java 的原始流水线。
- `source/dds`：DDS 管理、生产者、消费者和相关示例代码。
- `source/utils`：地图、工具和辅助能力。

## 前端目录

- `frontend/s/src` 等价于当前 Vite 源码目录中的 `frontend/s` 文件结构。
- `frontend/s/pages/WorkbenchPage.tsx`：任务输入、协同计划、算法、DDS 和执行时间线展示。
- `frontend/s/pages/DevicesPage.tsx`：设备注册中心状态展示和设备动作。
- `frontend/s/pages/TopicsPage.tsx`：DDS Topic、QoS、发布订阅链路和通信日志展示。
- `frontend/s/api/adapter.ts`：前后端 API 适配与 mock fallback。
- `frontend/s/store/useAppStore.ts`：前端状态管理。
- `frontend/s/types.ts`：前端 TypeScript 类型定义。
- `frontend/s/index.css`：界面样式。

## 数据与文档目录

- `idl`：IDL 数据结构定义。
- `dsl-output`：运行时生成的 DSL 产物。
- `generated-java` / `generated-src`：DSL 转 Java 的生成代码。
- `docs`：实验报告材料、算法说明、API 说明和 DDS 通信说明。
- `tools/api_smoke_test.ps1`：接口 smoke test 脚本。

## 原型定位

本项目是实验型系统原型，侧重展示无人系统意图协同链路、算法方案和工程结构。项目不直接控制真实车辆、无人机或道路设备，真实 DDS、真实地图路网和真实设备接入均属于后续扩展方向。
